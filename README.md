# Data Science Ecosystem — Jupyter Notebook Assignment

A foundational notebook assignment completed as part of the IBM Data Science Professional Certificate learning pathway.

## Overview

The notebook introduces the Jupyter environment and foundational data science concepts. It is intended as an introductory learning exercise rather than a full analytical research project.

## Repository Contents

```text
.
├── DataScienceEcosystem.ipynb
└── README.md
```

## Getting Started

1. Install Python and Jupyter Notebook, or use a hosted notebook environment.
2. Open `DataScienceEcosystem.ipynb`.
3. Read the Markdown explanations and execute the notebook cells in order.

To launch Jupyter locally:

```bash
jupyter notebook
```

## Learning Context

This project forms part of coursework associated with the IBM Data Science Professional Certificate. The notebook is preserved to document early progress with notebook-based technical communication.
